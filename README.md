# SGS Çalışma

Ufuk'a özel SMMM Staja Giriş Sınavı ve mesleki İngilizce çalışma uygulaması.

- Web: https://backpacker-dotcom.github.io/sgs-calisma/
- Android: `SGS.apk` (her derlemede güncellenir)

Bütün ders içeriği (`p/` klasörü) AES-256-GCM ile şifrelidir ve yalnızca sahibinin parolasıyla açılır.
Bu depoda okunabilir kaynak metni, soru ya da cevap anahtarı yoktur.
